# BakauBase visual direction

Source reference: `docs/brand/green-mood-board.png`

## Character

Calm, botanical, measured, and trustworthy. The interface should feel like a field notebook meeting an environmental operations dashboard—not a generic green SaaS template.

## Palette

| Token | Value | Use |
| --- | --- | --- |
| Forest | `#1F3A2B` | Navigation, headings, primary actions |
| Moss | `#5B7B4A` | Active vegetation, links, positive data |
| Eucalyptus | `#7FA08A` | Water/rainfall data, secondary accents |
| Sage | `#A8B89A` | Borders and quiet surfaces |
| Pistachio | `#C9D9A0` | Selected states and highlights |
| Mint mist | `#D6E4D0` | Panels and calm status backgrounds |
| Cream | `#F3F1E6` | Main application background |

## Typography

- Cormorant Garamond: page titles, major impact statements, and selected numeric emphasis.
- DM Sans: navigation, forms, maps, charts, tables, and body text.

## Interface rules

- Prefer flat bordered surfaces to floating cards and heavy shadows.
- Use rounded organic shapes selectively for brand moments, not every component.
- Keep charts and maps operational, labelled, and high contrast.
- Never use decorative emoji as interface icons.
- Keep field controls at least 44 px tall.
- Clearly label simulated, estimated, placeholder, and uncertified data.
